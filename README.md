# KompuTek — Company Profile Landing Page

Website company profile untuk toko komputer & service **KompuTek** (Bandung). Dibangun dengan HTML/CSS/JS vanilla, tanpa framework, dengan desain "industrial workshop" (palet charcoal + copper/amber).

## Preview

🌐 **Live demo:** https://dulkemot.github.io/LandingPage/

## Fitur

- Hero dengan **video background** (loop, muted, autoplay)
- Marquee, grid layanan (6), galeri bengkel, proses 4 langkah
- Daftar produk, 3 paket service, testimoni
- Form kontak + link WhatsApp langsung
- Animasi reveal saat scroll (IntersectionObserver)
- Responsif (mobile-first breakpoints)

## Aset

Semua gambar dan video diambil dari [Pexels](https://www.pexels.com/) — lisensi gratis, bebas komersial, tidak wajib atribusi.

## Deploy ke GitHub Pages

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save. Setelah ~1 menit, site live di `https://dulkemot.github.io/LandingPage/`
